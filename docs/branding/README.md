# Identidad visual — GERENZ DENT (propuesta v1)

| Archivo | Uso |
|---|---|
| `logo-horizontal.svg` | Login, encabezados, documentos |
| `icono-app.svg` | Ícono del launcher de Android (se exportará a PNG adaptativo) |

**Concepto:** un diente (odontología) con una insignia verde de "check" = *cita recordada y cumplida*,
que es justamente el propósito de la app.

## Paleta

| Token | Hex | Uso |
|---|---|---|
| `blanco` | `#FFFFFF` | Fondos, diente del ícono |
| `celeste` | `#3BB5E8` | Color primario, "DENT", fondo del ícono |
| `celeste-claro` | `#7FD6F5` | Degradados, fondos suaves |
| `verde` | `#22B573` | Acciones positivas (Enviar, Asistió), insignia |
| `verde-oscuro` | `#1E9E62` | Texto "GERENZ", botones (mejor contraste sobre blanco) |
| `gris-texto` | `#5E7A86` | Texto secundario |

Nota de accesibilidad: el celeste sobre blanco tiene poco contraste para textos pequeños; en la app,
el texto en botones irá en blanco sobre `verde-oscuro`, y el celeste se usará en fondos e íconos.

Tipografía sugerida: **Montserrat** (títulos) + **Inter** o **Roboto** (texto), ambas gratuitas (Google Fonts).
